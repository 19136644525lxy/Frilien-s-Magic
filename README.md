# Frilien's Magic | 芙莉莲的魔法

> 基于《葬送的芙莉莲》世界观的 Minecraft 魔法模组

**Minecraft 1.21.1 | NeoForge 21.1.250**

## 简介

重现芙莉莲世界中魔法师的战斗与生活。挥舞法杖释放穿透方块的攻击魔法，展开多边形护盾抵御伤害，在村庄中接受流浪魔法使的委托——从击杀僵尸到收集钻石，完成委托获取魔力药水与法术卷轴。

## 核心功能

### 法杖系统

- **芙莉莲法杖** — 支持全部 12 种战斗法术
- **菲伦法杖** — 支持攻击魔法与防御魔法

法杖使用 2D 贴图 + `neoforge:itemLayers` 加载器实现自发光渲染，第一/第三人称视角及地面掉落均有独立缩放参数。

### 战斗法术（12 种）

| 法术 | 类型 | 说明 |
|------|------|------|
| 佐尔特拉克 (Zoltraak) | 攻击 | 蓝白渐变激光，穿透方块，5 格范围群体伤害，520 点伤害 |
| 防御魔法 | 防御 | 多边形护盾（参考 Prismatic Shield），吸收伤害 |
| 飞行魔法 | 实用 | 创造飞行机制，切换法术不掉落，死亡后清除 |
| 破灭之雷 (Judradjim) | 攻击 | 雷电打击 |
| 地狱业火 (Vollzanbel) | 攻击 | 火焰魔法 |
| 破坏黑光 (BlackLight) | 攻击 | 黑色光束，25 点伤害 |
| 魔力挤压 (Mana Strike) | 攻击 | 魔力冲击 |
| 封印魔法 | 控制 | 封印目标 |
| 爆破魔法 | 攻击 | 爆炸半径 6 格，破坏方块，自定义魔法伤害类型（无视护甲） |
| 变出刨冰 | 实用 | 召唤刨冰食物 |
| 漂浮魔法 | 实用 | 漂浮效果 |
| 清洁魔法 | 实用 | 修复全身盔甲耐久，消耗与冷却随损坏程度动态变化 |

**法术轮盘**：按快捷键打开圆形轮盘选择已学法术，支持多页翻页（滚轮/箭头点击/方向键），中心头像按法杖区分（芙莉莲/菲伦），法术图标随数量动态缩放。

### 基础能力（3 种）

| 能力 | 说明 |
|------|------|
| 魔力探知 | 范围 32 格，使生物发光，持续时间随魔力上限增强 |
| 魔力隐藏 | 自定义 buff，降低生物仇恨范围，完全阻止索敌，持续时间随魔力上限增强 |
| 长距离魔法 | 被动能力，增加攻击魔法射程（16 + 魔力上限/500 倍） |

基础能力进入世界自动学会，通过按键设置绑定快捷键。

### 魔力系统

- 初始魔力 1000，上限 9999999
- 每 5 秒（100 tick）恢复 1 点
- 所有法术消耗魔力，基础能力不消耗
- 魔力条 HUD 支持拖拽定位、滚轮缩放（0.5~3.0）、显示/隐藏文字
- 左上角默认位置，编辑模式下可自定义

### 魔力药水

| 等级 | 效果 |
|------|------|
| Lv1 | 恢复魔力 |
| Lv2 | 恢复魔力 |
| Lv3 | 永久提升魔力上限 |
| Lv4 | 恢复魔力 |
| Lv5 | 永久提升魔力上限 |

药水使用饮用动画，消耗后不产生空玻璃瓶。

### 委托系统

- **委托村民**：村庄中的傻子村民（Nitwit）有 15% 概率变为「流浪的魔法使」，持续发光，不计入生物刷新上限
- **动态委托**：击杀类（19 种目标）与收集类（22 种目标），按权重随机选取，数量随机生成，大事小事灵活组合
- **聊天对话**：右键村民后在聊天框接受/拒绝/领取奖励
- **奖励池**：魔力药水、原版稀有矿物、法术卷轴（卷轴与高级药水概率极低）
- **无限委托**：领取奖励后村民进入 5 分钟冷却，冷却结束后可接新委托，不连续重复

### 自定义伤害类型

- `friliensmagic:magic` — 无视护甲（加入 `minecraft:bypasses_armor` 标签）
- 佐尔特拉克、黑光、爆破魔法均使用此伤害类型

## 创意栏

四个独立标签页：法杖、法术卷轴、魔力药水、食物。法杖同时保留在原版战斗标签页。

## 配置项

| 配置 | 默认值 | 说明 |
|------|--------|------|
| 防御护盾强度 | — | 护盾最大吸收量 |
| 魔力条缩放 | 1.0 | HUD 缩放倍率 |
| 魔力条显示文字 | true | 是否显示数值 |
| 委托村民刷新概率 | 0.15 | Nitwit 变为委托村民的概率 |
| 委托村民冷却 | 6000 tick | 接受/拒绝后冷却时间 |
| 收集检查间隔 | 100 tick | 收集委托进度检查频率 |

## 操作说明

1. **学习法术**：右键对应法术卷轴学习战斗法术
2. **法术轮盘**：在按键设置中绑定「法术选择轮盘」快捷键
3. **施法**：手持法杖右键释放轮盘选中法术
4. **基础能力**：在按键设置中绑定魔力探知/魔力隐藏/长距离魔法
5. **魔力条编辑**：在按键设置中绑定「魔力条编辑」和「魔力条开关」
6. **接受委托**：在村庄中寻找发光的「流浪的魔法使」，右键对话

## 技术特性

- **数据存储**：NeoForge AttachmentType 系统（自动序列化与客户端同步）
- **伤害拦截**：`LivingIncomingDamageEvent` 优先护盾吸收
- **网络通信**：CustomPacketPayload + StreamCodec
- **线程安全**：ConcurrentHashMap、CopyOnWriteArrayList、AtomicInteger
- **源码 JAR**：构建时自动生成 `*-sources.jar`
