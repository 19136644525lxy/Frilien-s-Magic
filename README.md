# Frilien's Magic | 芙莉莲的魔法

> 基于《葬送的芙莉莲》世界观的 Minecraft 魔法模组

**Minecraft 1.21.1 | NeoForge 21.1.250**（主版本，仓库根目录）
**Minecraft 1.20.1 | Forge 47.4.27**（移植版，`1.20.1/` 目录，功能保持一致）
**MIT License**

## 简介

重现芙莉莲世界中魔法师的战斗与生活。挥舞法杖释放穿透方块的攻击魔法，展开多边形护盾抵御伤害，在村庄中接受流浪魔法使的委托——从击杀僵尸到收集钻石，完成委托获取魔力药水与法术卷轴。

## 核心功能

### 法杖系统

### 基础能力（3 种）

| 能力 | 默认效果 | 随魔力上限增强 |
|------|----------|----------------|
| 魔力探知 | 范围 32 格，使生物发光 | 发光持续时间 = 200 + 魔力上限/10 tick |
| 魔力隐匿 | 自定义 buff，完全阻止索敌 | buff 持续时间 = 200 + 魔力上限/10 tick |
| 长距离魔法 | 被动，增加攻击魔法射程 | 射程倍率 = 16 + 魔力上限/500 |

- 基础能力进入世界自动学会，不消耗魔力
- 魔力隐匿使用自定义 `ManaConceal` 效果（三重反索敌：可见度归零 + 目标切换拦截 + 已有目标清除）
- 通过按键设置绑定快捷键

### 法术轮盘

- 按快捷键打开圆形轮盘选择已学法术
- 最多容纳 6 个法术，超出自动分页
- 翻页支持三种操作：滚轮（上滚上一页/下滚下一页）、点击 < / > 箭头、左右方向键
- 中心头像按法杖区分（芙莉莲/菲伦）
- 图标随法术数量动态缩放：`icon_scale = max(0.65, 1.0 - (count - 4) × 0.07)`
- 图标使用 `poseStack.scale` 渲染避免纹理重复
- 选中法术时图标下方显示中文名称
- 服务端三重校验：手持对应法杖、法杖支持该法术、玩家已学会该法术

### 魔力系统

- 初始魔力 1000，硬上限 9999999
- 每 5 秒（100 tick）服务端恢复 1 点，自动同步到客户端
- 所有法术消耗魔力，基础能力不消耗
- 魔力条 HUD：
  - 左上角默认位置（距边缘 10px），编辑模式下可拖拽定位
  - 滚轮缩放（0.5~3.0），默认 1.0
  - 显示/隐藏数值文字
  - 直接在 Screen 层渲染避免背景模糊
  - 文字随 GUI 缩放同步

### 魔力药水

| 等级 | 效果 |
|------|------|
| Lv1 | 恢复魔力 + 永久提升魔力上限 |
| Lv2 | 恢复魔力 |
| Lv3 | 永久提升魔力上限 |
| Lv4 | 恢复魔力 |
| Lv5 | 永久提升魔力上限 |

- 使用饮用动画（UseAnim.DRINK），消耗时间 32 tick
- 消耗后不产生空玻璃瓶
- Tooltip 显示恢复量和上限提升量

### 法术卷轴

- 右键使用学习对应战斗法术
- 卷轴物品 ID、模型文件、贴图文件名均与法术名对应
- 卷轴贴图文件名格式：`scroll_<法术id>.png`

### 委托系统

**委托村民**：
- 自定义实体 `QuestVillagerEntity`（继承 Villager，固定 Nitwit 纹理）
- 村庄中的原版傻子村民有 15% 概率标记为「流浪的魔法使」
- 创造模式可使用刷怪蛋（紫金渐变）直接生成
- 持续发光（`setGlowingTag`），不计入生物刷新上限（`setPersistenceRequired`）

**动态委托生成**：
- 击杀类（默认 19 种目标）与收集类（默认 22 种目标），按权重随机选取
- 数量在目标 minCount~maxCount 范围内随机生成
- 分三个层级：普通（权重 8-10）、罕见（3-5）、稀有（1-2）
- 不连续重复同一目标
- **目标与奖励均可用数据包自定义**（见下文「数据包自定义委托」）

**委托绑定**：
- 每个委托绑定来源村民 UUID，不同村民委托互不干扰
- 待定委托来自其他村民时，右键新村民会清除旧提议并生成新委托
- 领取奖励仅限来源村民

**聊天对话流程**：
1. 右键村民 → 聊天框显示委托提议（击杀 X × N 或收集 X × N）
2. 点击 [接受] / [拒绝]
3. 完成委托后右键同个村民 → 显示 [领取奖励]
4. 点击领取 → 收集类委托扣除背包物品 → 给予随机奖励

**奖励池**（默认值，可用数据包覆盖，见下文）：

| 奖励 | 权重 | 数量 |
|------|------|------|
| 初级魔力药水 (Lv1) | 30 | 2-5 |
| 中级魔力药水 (Lv2) | 25 | 2-5 |
| 高级魔力药水 (Lv3) | 15 | 1-3 |
| 铁锭 | 15 | 4-12 |
| 金锭 | 12 | 2-6 |
| 红石 | 10 | 8-16 |
| 钻石 | 8 | 1-3 |
| 绿宝石 | 8 | 2-5 |
| 青金石 | 8 | 4-12 |
| 超级魔力药水 (Lv4) | 6 | 1-3 |
| 终极魔力药水 (Lv5) | 3 | 1-2 |
| 法术卷轴（普通，9 种各） | 3-4 | 1 |
| 稀有卷轴（破灭之雷等 3 种各） | 1 | 1 |

权重是相对值（总权重约 200），不是百分比；调高某项权重就会更常出现。

**冷却机制**：
- 领取奖励后村民进入 5 分钟冷却（6000 tick）
- 冷却仅阻止生成新委托，不影响查看进度或领取已有奖励
- 各村民冷却独立

### 数据包自定义委托

委托的**目标**与**奖励**都可以用数据包完全自定义，改完 `/reload` 生效，不必重启。

```
data/<命名空间>/friliensmagic/quest_pools/kill.json       击杀目标
data/<命名空间>/friliensmagic/quest_pools/collect.json    收集目标
data/<命名空间>/friliensmagic/quest_pools/rewards.json    奖励
```

**合并规则**：内置默认值先加载，数据包条目按 `id` 覆盖同名项、追加新项。
所以只需写想改的条目，不必抄整套。

**载入通报**：`/reload` 后若有新数据包参与，会向所有在线玩家广播一条聚合消息
（一次 reload 只发一条，且只通报新出现的命名空间；删掉再放回会重新通报）。
数据包可用 `assets/<命名空间>/lang/<语言>.json` 翻译这条通报，键为
`friliensmagic.quest_pool_loaded`（`%1$s` 数量、`%2$s` 命名空间列表）。

完整教程（标准数据包结构、字段表、示例、全部内置条目 id、默认值对照、容错说明）：

**→ [examples/quest_pools/](examples/quest_pools/)**（标准数据包，可直接放进 `datapacks/`）
**→ [examples/dist/](examples/dist/)**（打包好的 zip）

## 进入存档时的提示

玩家进入存档会收到**两段互相独立**的提示：

| | 社群信息 | 欢迎语 |
|---|---|---|
| **时机** | **每次**进入 | 仅**首次**进入（按存档判定） |
| **位置** | 聊天栏 | 屏幕中央**标题** |
| **默认内容** | 模组仓库 + Discord 邀请 | 欢迎来到辛逝纪1314年，尊敬的魔法使 |
| **用途** | 服务器公告 | 入场致意 |

「首次」的记录存在主世界的 `data/friliensmagic_welcome.dat` 里，随存档走——
同一玩家换个存档会重新看到一次欢迎语。

### 社群信息（每次进入）

默认显示三行，其中两个网址是**可点击链接**（点击打开浏览器）：

```
欢迎加入魔法的世界，魔法使。
本模组仓库：https://github.com/19136644525lxy/Frilien-s-Magic.git
欢迎加入我们的服务器：https://discord.gg/JGpKs6GDFC
```

网址本身作为链接文字显示，这样任何语言的玩家都能看懂，不需要翻译网址。

服主一般会改成自己服务器的信息：

```
/friliensmagic welcome join set 欢迎来到 XXX 服务器！\nQQ 群：123456
```

**文本里只要出现上面那两个网址，会自动变成可点击链接**，不用特殊语法。

### 欢迎语（仅首次，标题形式）

屏幕中央以**标题**形式显示。聊天栏的消息容易被冲掉，标题更适合入场致意。

**多行文本**：第一行是主标题，其余合并成副标题（小一号字，位于主标题下方）。

#### 跟随玩家语言

默认文案走**翻译键** `friliensmagic.welcome.default`，由**客户端**按自己的语言渲染：

| 客户端语言 | 显示 |
|------|------|
| 简体中文 | 欢迎来到辛逝纪1314年，尊敬的魔法使 |
| English | Welcome to the 1314th year of the Sorrowful Era, honored mage. |

这一点是必须的：**服务端拿不到客户端的语言设置**，只能把翻译键发过去让客户端解析。
所以英文客户端不会看到中文。

#### 文案优先级

```
单玩家自定义  >  全局自定义  >  全局默认（翻译键，跟随玩家语言）
```

- **全局自定义 / 单玩家自定义** 是管理员写死的字面文本，原样发送，不做翻译
- 只有**走默认**时才交给客户端翻译

#### 显示时长

标题的淡入 / 停留 / 淡出可在配置里调（默认 10 / 70 / 20 tick）：

| 配置键 | 默认 | 说明 |
|--------|------|------|
| `welcomeTitleFadeIn` | 10 | 淡入时长（tick） |
| `welcomeTitleStay` | 70 | 停留时长（tick，20 = 1 秒） |
| `welcomeTitleFadeOut` | 20 | 淡出时长（tick） |

#### 标题自适应缩放

原版标题固定 4 倍（主标题）/ 2 倍（副标题）渲染，长文本在低分辨率或较大的
GUI 缩放下会超出屏幕。模组通过 Mixin 在每帧渲染前按「文本宽度 / 屏幕可用宽度」
重算缩放：大屏保持原版观感，小屏自动缩小到两侧留 10% 边距，分辨率或
界面尺寸（GUI 缩放）变化时即时生效。两个版本实现一致：

- 1.21.1 NeoForge：注入 `Gui.renderTitle`（Mixin 配置内置于 NeoForge，无需 refmap）
- 1.20.1 Forge：标题渲染内联在 `Gui.render`，改为拦截 `setTitle`/`setSubtitle`/`clear`
  缓存文本，避免 `@Shadow` 字段依赖 refmap 字段映射；注解处理器配置见
  `1.20.1/build.gradle`（手动传入 MixinGradle 原本注入的 `mappingTypes`/
  `reobfTsrgFile`/`outRefMapFile` 三个参数）

### 命令

> 需要权限等级 2（管理员）。`[玩家]` 可省略，省略即操作全局设置；
> 只接受**在线**玩家。

**欢迎语**（标题，仅首次）：

| 命令 | 作用 |
|------|------|
| `/friliensmagic welcome get [玩家]` | 查看（原样回显，便于确认中文） |
| `/friliensmagic welcome set <文本>` | 设置全局自定义文本 |
| `/friliensmagic welcome set <玩家> <文本>` | 设置某个玩家的专属文本 |
| `/friliensmagic welcome reset [玩家]` | 恢复默认（走翻译键） |
| `/friliensmagic welcome clear [玩家]` | 关闭提示 |
| `/friliensmagic welcome forget [玩家]` | 清空「已提示」记录，下次进入重新看到 |

**社群信息**（聊天栏，每次进入）：

| 命令 | 作用 |
|------|------|
| `/friliensmagic welcome join get` | 查看当前社群信息 |
| `/friliensmagic welcome join set <文本>` | 设置自定义文本（网址自动变链接） |
| `/friliensmagic welcome join reset` | 恢复默认 |
| `/friliensmagic welcome join clear` | 关闭 |

**中文与空格**：直接输入即可，无需转义。`set` 的参数用 greedy string 解析，
所以空格、中文标点都能保留。例：

```
/friliensmagic welcome set 欢迎来到辛逝纪1314年，尊敬的魔法使
/friliensmagic welcome set Steve 欢迎你，Steve
/friliensmagic welcome join set 欢迎加入！\n仓库：https://github.com/19136644525lxy/Frilien-s-Magic.git
```

**换行**：命令里敲不了真换行，用字面 `\n` 表示，会还原成多行。

### 改默认文案

两个默认文案都是普通翻译键，改模组语言文件里的对应项即可：

| 翻译键 | 内容 |
|--------|------|
| `friliensmagic.join.line1` | 社群信息第 1 行 |
| `friliensmagic.join.line2` | 社群信息第 2 行（`%s` 是仓库链接） |
| `friliensmagic.join.line3` | 社群信息第 3 行（`%s` 是 Discord 链接） |
| `friliensmagic.welcome.default` | 欢迎语标题 |

> 社群信息**一个键一行**，不是一整段。原因是原版语言文件里的 `\n` 是**字面**的
> 反斜杠加 n，翻译时不会被转成换行——写成一整段会挤在同一行显示。

数据包也能覆盖，见「数据包自定义委托」一节对语言文件的说明。

## 技术特性

- **数据存储**：NeoForge AttachmentType 系统（自动序列化、客户端同步、copy-on-death 可选）
  - `MANA`：玩家魔力值
  - `SHIELD`：护盾状态（强度/最大强度/激活）
  - `LEARNED_SPELLS`：已学法术列表
  - `SELECTED_SPELL`：当前选中法术（按法杖独立存储）
  - `FLIGHT`：飞行状态
  - `QUEST`：玩家委托数据（9 字段，含来源村民 UUID）
  - `QUEST_VILLAGER`：村民委托标记 + 冷却
- **伤害拦截**：`LivingIncomingDamageEvent` 优先护盾吸收
- **反索敌**：`LivingVisibilityEvent` + `LivingChangeTargetEvent` + `EntityTickEvent.Pre` 三重拦截
- **网络通信**：CustomPacketPayload + StreamCodec（手动实现 9 字段 QuestData 编解码）
- **线程安全**：ConcurrentHashMap、CopyOnWriteArrayList、AtomicInteger
- **源码 JAR**：构建时通过 `withSourcesJar()` 自动生成 `*-sources.jar`
